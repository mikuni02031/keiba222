# 競馬パーティー 🏇

スマホ1台をみんなで回して遊ぶ、3D競馬ベッティングゲーム。ビルド不要の静的サイトなので GitHub Pages にそのまま置けます。

## あそびかた

1. 人数（2〜8人）・初期コイン（100〜1000 / 自由入力）・レース数（2〜5 / 自由入力）を決める
2. 出馬表（単勝オッズ・勝率つき）を見て、スマホを回しながら1人ずつベット
   - **単勝**：1着を当てる
   - **馬単**：1着→2着を順番どおりに当てる
   - **3連単**：1着→2着→3着を順番どおりに当てる
3. 全員ベットしたら3Dレース（実況つき）
4. 払い戻し → 次のレースへ。最終レース後に結果発表
5. **(トップのコイン − ベベのコイン) ÷ 50** 杯（切り捨て）がベベのお酒。3杯で「ウォッカ1カウント」
6. お酒は「お酒帳簿」にたまり、「飲んだよ！」ボタンで消費。ゲームをまたいで持ち越し

## ルールの細かいところ

- 出走は毎回7頭。歴代の名馬 + 特別出走馬（カミノ / イイダタツヤ / サトフカ / イッシキ）からランダム
- レースタイプ：1強（1番人気 1.2〜1.9倍）/ 2強（上位2頭が2倍台）/ 3強 / 本命やや優勢 / 混戦 / 大混戦 / ドリームレース
- オッズは勝率から計算（払戻率90%）。着順は表示している勝率どおりに抽選されるので、オッズと結果は必ず整合する
- 馬単・3連単の倍率上限は 999.9倍
- コインが0になった人には、次のレース開始時に初期コインの10%を救済
- 帳簿は localStorage / IndexedDB / Cache Storage / Cookie の4か所に保存し、どれかが残っていれば自動復元。
  ブラウザの「サイトデータを全消去」には勝てないので、帳簿画面の「バックアップコード」も用意

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` / `css/style.css` | 画面 |
| `js/main.js` | ゲーム進行・UI |
| `js/logic.js` | オッズ生成・着順抽選・払い戻し |
| `js/raceplan.js` | 着順に合わせたレース展開と実況の台本 |
| `js/race3d.js` | 3Dレースのカメラワーク・HUD |
| `js/track.js` / `js/horse.js` | 競馬場と馬・騎手の3Dモデル（すべてコードで生成） |
| `js/audio.js` | 効果音（WebAudio合成）と実況の読み上げ |
| `js/storage.js` | お酒帳簿の保存 |
| `vendor/three.module.min.js` | three.js r160（MIT License） |

## ローカルで動かす

```bash
python .claude/devserver.py 8766
```

`http://localhost:8766/` を開く。`?demo=1` を付けるとレース演出だけをすぐ確認できます（`&env=day|sunset|night|rain`、`&type=solo|duo|…`）。
